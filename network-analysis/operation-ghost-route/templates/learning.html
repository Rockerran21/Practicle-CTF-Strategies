ANALYST FIELD GUIDE

Techniques, not answers.

Use this guide when you understand the evidence but need help choosing the next operation.

01

Correlate before decoding

Build a UTC timeline using usernames, hostnames, source IPs, process ancestry, URLs, and hashes. Start from rare events and pivot into adjacent sources.

02

Recognize DNS tunnelling

Look for many high-entropy labels beneath one uncommon parent domain, a consistent source, numeric sequence markers, and a short time window.

03

Reassemble in sequence

Sort chunk counters numerically, remove the counter and separator, then concatenate the encoded data before decoding it.

04

Restore Base32 padding

DNS labels often omit equals signs. Add padding until the complete encoded string has a length divisible by eight.

05

Follow the endpoint command

Process arguments can document an attacker's transformation pipeline. Distinguish hexadecimal characters from the bytes they represent.

06

Inspect before assuming text

After reversing encryption or obfuscation, check for compression signatures. Common zlib streams begin with 78 01, 78 9c, or 78 da.
