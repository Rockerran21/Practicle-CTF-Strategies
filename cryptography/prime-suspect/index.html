01 // INCIDENT BRIEFING

A routine deployment left a cryptographic fingerprint.

Forbes College's lab deployed two small RSA gateways for a classroom exercise. Both generated keys immediately after the same virtual machine image booted.

A monitoring sensor captured one encrypted diagnostic message and both public keys. The administrator insists that public keys cannot reveal the message. The key-generation process says otherwise.
